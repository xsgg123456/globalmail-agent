# 独立售后政策修订 v2

本目录只修订 v1 的售后政策，补齐图片与其他来源的逐条件证据要求；不重新制作商品、场景或整个知识包。政策版本为 2.0.0，来源仍是隔离模拟规则，**未发布、业务内容核对待完成**。技术生成或审查通过不表示业务负责人已核准。

`authoring/policy-profile.json` 是唯一编辑源。`build_policy.py` 同次生成规则、中文说明与 `policy-bundle.json`，清单绑定三者摘要、生成器、解释器及 schema 版本、范围、拟生效时间、替代关系和 v1 原字节引用。已批准的 30 天、365 天、20%（2000 基点）、7 天等原规则保持不变。

```powershell
python -X utf8 data/knowledge/v2/build_policy.py
python -X utf8 data/knowledge/v2/build_policy.py --check
```

生成器仅离线读本目录和 v1 政策，写本目录的三个生成物，不发布或改动 v1。`--check` 对照完整字节，不执行写入。

原业务场景继续显式绑定 [v1](../v1/README.md)，不能静默改用 v2。图片专项后续须明确选取已核对版本；Phase 6 才实现规则与可读说明的同版本正式发布。未发布时资格预览即使计算为符合条件，仍返回 `authorized:false`；摘要 `decision_id` 不是执行令牌，未来写操作必须重新计算。

照片只支持政策明确允许的申报或可见外观条件。订单、金额、客户具体选择、库存、兼容、仓库收件、质检和执行成功均须来自对应工具或已验证模拟记录。v1 没有证据映射时，不允许将视觉观察当业务工具事实。购买备用件不等于免费售后资格。
