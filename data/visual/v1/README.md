# 客户图片专项开发集

35 个真实字节的合成 AI 输入，覆盖三品牌模拟关联；三次运行及密集截图全图/裁剪共108次请求。18个VIS编号的完整分支见 [branch-matrix.json](branch-matrix.json)，不与原知识包72个业务输入混算。

给业务人员看的中文对照：[review.html](review.html)。包含图片、客户在问什么、建议处理方式及每次AI实际表现。图片与答案均由项目生成，**人工核对尚未完成**。不是真实客户缺陷照片、厂家资料或独立保留集，不据此报告生产准确率。

- `manifest.jsonl`：消息、受控图片摘要、客户/分支/用途/可见序号、模拟业务事实；请求端仅允许加载这些输入。
- `images/`：原始六格合成图、固定非生成式裁剪及程序绘制的虚构订单截图。三格式标签同源；模糊样本不允许恢复不存在的字符。
- `source-provenance.json`、[生成提示](generation-prompt.txt)：来源和使用依据。模拟品牌关系不证明照片对应真实SKU。
- `evaluation/labels.jsonl`：字段、观察、允许分流与禁止动作；评估器读取，模型请求程序不读取。
- `freeze.json`：输入、标签、分支与来源摘要。更改产生新实验；旧输入/标签/结果保存在对应运行目录，不覆盖历史成绩。
- `validation.json`：离线图片/清单校验，不能代表模型或产品通过。

仅使用虚构999前缀订单和合成照片，不连接生产查询，不上传客户个人资料。不自动访问图片中的网址或把图像加入共享知识库。VIS-013/014/016/017和相关正式事务/缓存/UI分支只冻结输入与步骤，归Phase 8/12/13。

重建与实测命令见 [实验README](../../../globalmail-agent/vision-spike/README.md)；总结果见 [图片实验报告](../../../docs/verification/VISUAL-VALIDATION.md)。
