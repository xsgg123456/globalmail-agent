# 知识检索开发查询集

版本：v1；日期：2026-10-07。文件：`retrieval-queries.jsonl`。仅供 KNOWLEDGE-DESIGN 第 10 节知识管线专项实验使用，不属于正式知识、生产验收集或历史业务评测集。

## 编制顺序与完成标准

1. 先读设计第 7/9/10 节、manifest、绑定及允许正文，确认适用范围；通过标准为每条目标证据均有明确 SKU、品牌、simulation/rag 和生效时间依据。
2. 据正文一次编写全部 60 条自然英德查询并固定标签；通过标准为 36 正例、12 边界、6 无答案、6 多证据，英德各半，覆盖 8 产品族和案例/政策。
3. 对 schema、ID、语言分布、证据逐字短语及资格做确定性检查；通过标准为全部通过。没有查询模型、Embedding API、相似度分数或召回结果反馈参与标签修改。自检只修正源文、约束或标注本身的问题。

## 标签与计分语义

每行固定字段：

- `query_id/kind/language/query/sku/mode/as_of/evidence/reason/split`；`split` 始终为 `dev`。
- positive 恰好一项 evidence；multi_evidence 至少两项；boundary、unanswerable 的 evidence 为空。
- evidence 的 `document_id` 是目标逻辑资料 ID；`required_any` 至少两个源正文逐字中文短语，表示同一证据需求的可选命中锚点。命中要求同时满足目标文档 ID 和至少一个短语，不能只凭“召回该文档任意片段”计分。
- 多证据问题需分别满足所有 evidence 项。记录每项覆盖及整题覆盖，不能只检查其中一份。
- `required_any` 是片段命中的保守代理，不能取代答案正确性、完整条件、安全警告和引用定位的审查。它不是完整参考答案；某些题同时涉及两个条件，命中其中一个锚点不代表答案已经完整。
- 切分器若规范化空白，计分时可对源短语和候选文本使用同一明确的空白规范化；不能用模糊语义匹配静默放宽标签。保存原始引用位置。

boundary 要求**适用候选为空、越界返回为零**。无答案题则可能合法召回相关说明或“需核实”的警告；这不等于越界。它检验现有资料不能支持所问事实时是否弃答/补问/转人工。未经独立阈值校准和答案审查，不把“无答案题有相关块”直接记为越界错误，也不把非空候选当成有答案。

政策查询在自然语言中补齐了品牌/市场/渠道背景；无 SKU 清单的 POL-SIM-V1 只在已登记产品且品牌属于显式政策范围时允许作为候选。实际业务执行仍要从结构化工具核验市场、渠道、币种、签收日、库存等条件；这套固定 schema 不承担完整政策授权。

## 自检方法与结果

使用 Python 标准库做本地确定性检查，没有安装库或向外部服务发送内容：

1. 逐行 JSON 解析，字段集合完全一致；检查字符串非空、kind/language/mode 枚举和 UTC ISO 时间。
2. 精确检查 60 行、ID 连续且唯一、查询正文不重复，以及 36/12/6/6 和各类别英德对半。
3. 对 evidence 项检查结构、目标文档不重复、每项至少两个不同中文短语；96 个短语均在对应 Markdown 正文逐字存在。
4. 用 manifest + binding 对 SKU、由显式 SKU 绑定导出的品牌、rag、allowed_modes、available_at 做交集；42 条有答案查询的 48 项证据全部适用，12 条边界候选全部为空，6 条无答案均为已知且允许的 SKU。
5. 检查 positive 覆盖全部 8 产品族、8 篇 SOP、5 个案例和政策说明；边界原因精确为未知 SKU/不允许 mode/早于生效时间各 4 条。
6. 人工语义自检关注：问题能否由指定资料回答、多个文档是否分别提供独立信息、案例已知与未知是否分开、无答案是否确实缺少请求事实。这里“人工语义自检”指编制 Agent 的逐题检查，尚未获得业务专家或独立语言审校签字。

结果：以上确定性检查全部通过；48 项目标证据、96 个短语检查通过。检索效果、生成答案质量、阈值、延迟和费用均尚未由此文件证明。

## 已知限制与下一步使用规则

- 这是根据当前小型中文 simulation 包编制、用于比较配置和校准的开发集，不能代表独立测试性能。必须另建未参与调参的检索验收查询；现有业务 holdout 保持隔离。
- 所有目标答案均在 Markdown；PDF 的等价段落可能出现相同事实，严格文档 ID 计分会把仅召回 MAN 的结果视为未满足指定 SOP 标签。报告需同时保存实际引用供审查，不能在看过检索结果后临时把失败样本改成宽松标签。PDF 解析质量应由独立逐页/结构实验评价，本集不能替代 AC-055/063 的图表、单位和图片步骤检查。
- schema 没有单独的 brand 字段，SKU 可导出品牌，KQ-040 只检验跨品牌样式的未知 SKU 被拒绝；它不能单独证明“显式请求品牌与已知 SKU 冲突”的过滤正确性。该行为应另以知识服务确定性测试验证。
- 两种语言各 30 条是均衡覆盖，并非真实客户流量抽样；含案例结果的查询是显式询问已审读示例，不作为真实新来信分布代表。德语标注尚需独立母语审校。
- manifest 的 `prepared_not_indexed` 不等于正式发布。这套查询只为隔离实验的允许输入定义适用性，不证明发布、撤销、删除、缓存和迟到任务的正式生命周期已经实现。
- 数字政策均为 POL-SIM-V1 的内部演练规则，不能解释为正式品牌承诺。查询和 reason 不新增厂家参数、通用维修动作或跨型号兼容结论。
